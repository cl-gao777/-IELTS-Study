# 0008 · 独立词根词缀课程

状态：已接受，2026-10-22。

## 决策

词根词缀课程使用独立目录、教学、练习与记录，不接入到期复习或 FSRS。完成表示完成一次练习，不表示掌握。课程文本本地打包，来源、核对日期与许可逐课记录，课程内容许可与程序 MIT 许可分别说明。

练习开始时冻结课程、问题、选项和例句。教学资料从练习视图卸载，提示必须主动请求；核对后显示解析。首次作答身份由服务端历史确定，结束未完成的练习不会清除已核对样本。整课和弱项重练保留原始首次记录，后续完成轮次轮换例句。

会话采用全局恢复标识 `dataEpoch`、递增 revision 和唯一操作 ID。评分事务同时保存原回答、提示状态和冻结答案；重复提交返回原结果，结果不明先查询。内容变更拒绝旧题面，浏览器保留独立输入副本供导出。刷新及重新打开保持暂停。

词根计时使用稳定片段 ID 和累计秒数，服务端仅登记增加量。与词汇页共享前台计时锁；目录、结果、暂停和后台不计时。通用页面心跳排除该路由。时间写入 `study_sessions` 的 `Morphology` 区域，计入首页实际总时长，排除词汇每日目标。

## 与词汇学习的边界

浏览和答题不创建个人词条，不改变原 FSRS。只有明确选择「加入词汇学习」才建立手选义项来源。同义项使用稳定 ID 跨课去重；保留个人释义、笔记、暂停与历史，不切换当前课程。原选词流程仍检查到期优先、进阶资格和 B2/C1 顺序；未核验等级不猜填。

## 备份

完整备份升级为 v6，新增九张词根内容、会话、审计、计时与手选关联表。已知完整 v1–v5 升级为空词根记录，不补造历史。v6 严格核对冻结题面、首次样本、成绩、关联与计时账本。恢复事务轮换全局标识并提高会话版本，暂停恢复的会话；失败沿用原有数据库与附件回滚机制。保留的输入副本从不自动导回数据库。

## 代价

冻结完整内容增加备份体积，但使旧结果可解释，并避免课程更新重写历史。词汇仍保持每词一份 FSRS，义项手选仅增加内容来源，不建立第二份调度器。
