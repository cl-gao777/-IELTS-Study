# 黑白灰学习工作台

2026-10-23。依据用户提供的 shadcn/ui 风格参考与截图调整现有产品，采用中性表面、Geist、胶囊控件和轻微卡片层次，保留真实学习内容；不复制展示网站的营销布局。

## 视觉规范

浅色 canvas #f5f5f5、paper #ffffff、ink #0a0a0a、muted #707070（参考稿 #737373 在浅灰底上略加深，以满足4.5:1对比度）、hairline #e5e5e5。深色为中性黑灰，主操作反转为浅底深字。旧 forest/leaf 变量为中性兼容别名，只有成功、错误和警告使用语义颜色。卡片圆角24px、控件18px、内部结构10px；交互目标至少44px。界面14px，学习题面、输入和长文至少16px。

字体使用本地 Geist Latin variable WOFF2，中文系统回退，长文衬线保留。字体来源和 OFL 许可随 public/fonts/geist 打包，不依赖远程字体服务。

## 导航与学习边界

64px 固定顶栏提供六个常用入口和“更多”中的其他页面。小于1024px使用原生dialog抽屉。“更多”使用原生details和链接，支持方向键、Home/End、Escape、Tab离开和外部点击；抽屉关闭恢复触发按钮焦点。导航不会显示题面词义或答案。

普通页面最大1280px，词汇960px；材料和考试工作区使用可用宽度。全屏工作区不预留站点顶栏，普通滚动区和工具栏依据共享导航高度计算。两主题、减少动效、焦点与小屏布局一并维护。

本次无API、数据库、评分、FSRS或恢复协议变更。视觉验收使用隔离数据库；正式发布前按最新数据备份并核对学习记录及私人附件，不将这些资料上传GitHub。

## 安全补丁

构建时发现现有Next.js16.4.0安全公告，用户明确选择本轮一并升级。Next.js及eslint-config-next锁定16.4.1；官方依据：https://nextjs.org/blog/nextjs-security-update-october-14-2026 。依赖变更单独提交并重新验收，旧正式依赖树和构建均保留以便回退。
